## 🧠 AGI Capability Fabric

Nessy models AGI functionality as composable runtime contracts. Each capability is implemented as a separate crate, allowing for modular development and easy integration with other capabilities.

| Domain | Capability surface | Crate |
|:--|:--|:--|
| **Reasoning** | structured reasoning, verification, reflection, hypotheses, theorem proving | `reasoning` (WIP) |
|  | - *Structured Reasoning*: Provides a way to reason about complex systems using logical inference and deductive reasoning. |  |
|  | - *Verification*: Ensures that the system behaves as expected by checking preconditions, postconditions, and invariants. |  |
|  | - *Reflection*: Allows the system to reason about its own internal state and behavior. |  |
|  | - *Hypotheses*: Generates and evaluates hypotheses to explain observed phenomena. |  |
|  | - *Theorem Proving*: Automatically proves mathematical theorems using logical deduction. |  |
| **Planning** | decomposition, hierarchy, long-horizon plans, replanning, scheduling | `planning` |
|  | - *Decomposition*: Breaks down complex tasks into smaller, manageable subtasks. |  |
|  | - *Hierarchy*: Organizes tasks into a hierarchical structure, allowing for better coordination and resource allocation. |  |
|  | - *Long-horizon Plans*: Generates plans that consider long-term goals and constraints. |  |
|  | - *Replanning*: Adapts plans in response to changes in the environment or task requirements. |  |
|  | - *Scheduling*: Assigns tasks to resources over time, optimizing for resource utilization and task completion. |  |
| ... (other capabilities remain unchanged) |
